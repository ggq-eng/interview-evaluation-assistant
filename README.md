# interview-evaluation-assistant

> 来源分类：**待确认** ｜ 导出批次：review

构建 AI 面试评估助手网页工具。当用户需要创建用于 HR 面试场景的评估工具时使用，包括：岗位 JD

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/interview-evaluation-assistant        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/interview-evaluation-assistant   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。
